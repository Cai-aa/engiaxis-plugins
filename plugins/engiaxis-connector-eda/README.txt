Included Engineering Software Adapters:
  - EasyEDA Pro (JLC EDA) (嘉立创EDA 专业版 (EasyEDA Pro)) [easyeda-pro]
  - KiCad (KiCad) [kicad]
  - Altium Designer (Altium Designer) [altium-designer]
  - Keysight ADS (Keysight ADS (先进设计系统)) [ads]

Quick Start:
  1. Import this zip/folder in ChatGPT Desktop -> Plugins, OR run .\Install-ChatGPT-Desktop.ps1 -OpenWizard
  2. Activate your offline license key (EA1.xxx) in the Setup Wizard or ask the AI to call connector_activate_license.
  3. Run Setup on your installed CAD / CAE / EDA software.

Visual Configuration Wizard (anytime):
  node runtime\connector.mjs wizard --edition eda
